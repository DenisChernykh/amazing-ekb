# Amazing EKB — гид по Екатеринбургу

Веб-приложение и Telegram Mini App для знакомства с местами и публикациями о Екатеринбурге.

## Возможности

- Каталог мест и контента, навигация по категориям.
- Интеграция с Telegram и работа с публикациями.
- Серверное приложение Next.js, Prisma и интерфейс на React.

## Инженерные акценты

- Разработка контентного продукта с frontend, серверной частью и моделью данных.
- Интеграция веб-интерфейса с окружением Telegram Mini Apps.
- Адаптивный интерфейс каталога и повторно используемые компоненты.

## Стек

React, Next.js, TypeScript, Prisma, Tailwind CSS, Swiper.

## Навигация по коду

- [src/](src/) — исходный код.
- [prisma/](prisma/) — схема данных и миграции.

## Разработка

Инструменты: pnpm.

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
```
