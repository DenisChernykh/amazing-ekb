# Amazing EKB — места Екатеринбурга в одном каталоге

Веб-приложение помогает выбрать, куда сходить в Екатеринбурге. В нём собраны места с фотографиями, описаниями, категориями, информацией о стоимости и ссылками на карту и публикации в Telegram.

Каталог можно открыть в браузере или внутри Telegram как Mini App. Читателю проще найти подходящее место по категории и посмотреть его карточку.

[Открыть сайт](https://amazing-ekb.vercel.app/)

## Что можно делать

- **Просматривать каталог:** выбирать категорию и открывать карточки мест.
- **Смотреть фотографии:** листать галерею, читать описание и переходить к исходной публикации.
- **Планировать посещение:** посмотреть указанную стоимость и открыть место на карте.
- **Использовать Telegram:** открывать приложение внутри мессенджера; приложение получает данные входа через интеграцию с Telegram.
- **Вести каталог:** администратор добавляет место, связывает его с публикацией, выбирает категорию и главную фотографию.
- **Переносить контент из канала:** служебные сценарии загружают публикации и фотографии, объединяют сообщения альбома и сохраняют их для каталога.

## Что я разработал

- **Пользовательский интерфейс на React и Next.js:** сетку карточек, фильтр категорий, страницу места и галерею фотографий с адаптацией под экран телефона.
- **Формы управления контентом:** добавление карточки, проверку данных, выбор категории и обложки.
- **Серверную часть:** получение и сохранение мест, категорий, публикаций, изображений и профилей пользователей.
- **Интеграцию с Telegram:** вход внутри Mini App, загрузку материалов канала и связь карточки с исходной публикацией.
- **Работу с фотографиями:** подготовку изображений из публикаций, сохранение файлов и выбор главного изображения.
- **Структуру приложения:** отделил интерфейс и серверные действия от правил работы с карточками и доступа к базе. Сценарии создания и получения места можно читать отдельно от деталей Next.js и Prisma.

## Как устроен каталог

У карточки места есть собственные поля: название, категория, стоимость и ссылка на карту. Она связана с исходной Telegram-публикацией, её текстом и фотографиями.

Такое разделение позволяет использовать материалы канала в каталоге и дополнять их структурированной информацией. Фильтрация работает по категориям, а ссылка на публикацию сохраняет путь к полному материалу.

## Локальная разработка

Используется pnpm. Для запуска нужны PostgreSQL с переменной `DATABASE_URL` и настройки используемых интеграций Telegram и Supabase. Локальные значения и секреты не добавляются в Git.

```sh
pnpm install
pnpm dev
```

```sh
pnpm build
```

Схема базы находится в [prisma/schema.prisma](prisma/schema.prisma), команды генерации клиента, миграций и импорта — в [package.json](package.json).
